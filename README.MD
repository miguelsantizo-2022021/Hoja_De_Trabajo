Al finalizar la actividad el estudiante será capaz de:
Comprender el funcionamiento del módulo http de Node.js.
Crear un servidor HTTP sin utilizar Express.
Implementar rutas para responder diferentes solicitudes.
Manejar los métodos HTTP (GET, POST, PUT y DELETE).
Leer y enviar información en formato JSON.
Probar servicios REST utilizando Postman.
Organizar el proyecto siguiendo buenas prácticas.
